# 🛠 Telegram-бот приёма заявок для сервиса ремонта техники

Бот принимает заявки от клиентов через пошаговую анкету, сохраняет их в базу и сразу присылает администратору. Админ управляет заявками из удобной панели с кнопками, переписывается с клиентом прямо через бота и выгружает отчёт в Excel.

**Стек:** Python 3.10+, aiogram 3, SQLite (aiosqlite), FSM, openpyxl

## Возможности

**Для клиента**
- Анкета из 4 шагов: услуга → имя → телефон → описание, затем проверка и подтверждение
- Телефон отправляется кнопкой «Поделиться контактом» или вводится вручную (с проверкой формата)
- Проверка ввода на каждом шаге, отмена в любой момент
- «Мои заявки» — список своих заявок со статусами
- Уведомления о смене статуса
- Переписка с администратором прямо в чате бота

**Для администратора — отдельная панель с кнопками**
- 🆕 Новые / 🔧 В работе / 📚 Все заявки — списки, заявка открывается одним нажатием
- 🔍 Поиск заявки по номеру (или `/lead 15`)
- Смена статуса кнопками под заявкой, клиент получает уведомление
- 💬 **Диалог с клиентом:** текст, фото, файлы и голосовые пересылаются с пометкой «👨‍💼 Администратор», ответы клиента приходят админу с кнопкой «↩️ Ответить»
- 📊 Статистика по статусам в процентах
- 📤 Выгрузка в **Excel (.xlsx)**: оформленная шапка, цвет по статусам, фильтры, лист со статистикой
- Отдельное меню команд для админов, несколько админов через `ADMIN_IDS`

## Структура проекта

```
lead_bot/
├── bot.py            # точка входа: запуск, меню команд
├── config.py         # чтение настроек из .env
├── database.py       # SQLite: заявки и диалоги
├── states.py         # состояния: анкета, поиск, диалог
├── keyboards.py      # все кнопки и список услуг
├── texts.py          # справки и карточки заявок
├── export.py         # генерация Excel-отчёта
├── filters.py        # фильтр «только для админов»
├── handlers/
│   ├── chat.py       # диалог админ ↔ клиент
│   ├── admin.py      # панель администратора
│   └── user.py       # сценарий клиента
├── tests/smoke_test.py  # офлайн-прогон сценария без Telegram
├── requirements.txt
└── .env.example
```

## Запуск

```bash
python -m venv venv
venv\Scripts\activate             # Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # Mac/Linux: cp .env.example .env
```

Впишите в `.env` токен от [@BotFather](https://t.me/BotFather) и свой ID от [@userinfobot](https://t.me/userinfobot), затем:

```bash
python bot.py
```

Администратору нужно один раз нажать `/start` у бота. После первого `/start` перезапустите бота, чтобы появилось админское меню команд.

## Как сменить тематику

Список услуг находится в `keyboards.py` (`SERVICES`), тексты — в `texts.py` и `handlers/user.py`. Логика от темы не зависит.

## Проверка без Telegram

```bash
python tests/smoke_test.py .
```

Скрипт подменяет сетевую часть бота и проигрывает весь сценарий: анкету, панель админа, диалог, смену статусов и выгрузку Excel.
